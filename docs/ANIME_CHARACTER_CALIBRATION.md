# تجهيز شخصية أنمي للمحرك السينمائي

ابدأ من [قالب المشهد](../examples/cinematic-runtime-lab/ANIME_CHARACTER.scene.example.json). القالب قابل للتحميل مباشرة عند حل مسارات الأصول نسبةً إلى مجلد `examples/cinematic-runtime-lab/`. يستخدم أطلس ليلى الموجود لعرض النتيجة المرجعية. عند استعمال رسم جديد، غيّر معرّف الشخصية والصورة، واستبدل مقاسات وقصّات المثال بالمقاسات المقاسة على الرسم الجديد.

## تجهيز الطبقات والمعايرة

1. اختر رسم PNG أو WebP شفافًا. سجّل أبعاد لوحة الشخصية الكاملة `W × H` في وضعية الراحة. اعمل على نسخة منه واحتفظ بالأصل للمقارنة.
2. افصل الجسم والرأس عند الرقبة، وحافظ على تداخل صغير خلف نقطة الدوران. امسح من طبقة الرأس الملامح التي ستُرسم منفصلة، ثم املأ الفراغ بلون وتدرج الجلد من الرسم نفسه. استخرج من الأصل الفم المغلق والعينين المفتوحتين والحاجبين.
3. جهّز الجفنين المغلقين وارسم الفم في وضعيات `closed` و`open` و`round` و`wide` و`teeth`. خصّص `eye_left` و`eye_right` للعينين و`brow_left` و`brow_right` للحاجبين. المقصود باليمين واليسار في القالب جهة الرسم.
4. رتّب القصاصات في أطلس شفاف، مع هامش شفاف بين البلاطات. سجّل لكل قصاصة `sourceRect` بأعداد صحيحة من أعلى يسار الأطلس. اجعل `assetId` للقصاصات المشتركة يشير إلى معرّف الأطلس نفسه، كي تُفك الصورة مرة واحدة لكل مجموعة مشاهد تستخدمه.
5. إذا كان موضع القصاصة داخل لوحة الشخصية هو `(left, top)` ومقاسها `(w, h)`، واخترت نقطة ارتكازها `(px, py)` بوحدات اللوحة، احسب الحقول التالية.

| حقل التخطيط | القيمة |
| --- | --- |
| `x`, `y` | `px / W`, `py / H` |
| `width`, `height` | `w / W`, `h / H` |
| `pivotX`, `pivotY` | `(px - left) / w`, `(py - top) / h` |

اختر الارتكاز عند الرقبة لطبقة الرأس. اضبط ترتيب الجسم والرأس والملامح بحقل `z`. عيّن `view` صراحة إلى `front` أو `side` وفق الوضعية المؤلَّفة. عند تغيير الرسم أو زاويته، أعد قياس التخطيط والقصاصات. عند إضافة تعبير، أضِف طبقة حاجب بقيمة `variant` تحمل اسم التعبير مع إبقاء `neutral`.

## التحقق قبل الإدراج

- افتح المشهد وتأكد من `renderer.metrics.lastDraw.faceRigValid[characterId]`، وراجع موضع الفم في الراحة وفي الوضعيات الأربع الأخرى.
- قارن الصورة الأصلية والوجه المركّب بالإضاءة والتكبير نفسيهما. راجع الجفنين عند الرمش، اتصال الرأس بالرقبة، واتجاه الوجه بعد الانعكاس.
- جرّب جملة فيها أصوات مدوّرة ومفتوحة ووقفة بعلامة ترقيم. راقب المتحدث والمستمع، ثم اختبر الانتقال وإعادة التشغيل دون إنترنت.
- شغّل `npm test`، ثم `npm run build:cinematic-runtime`، ثم `python tests/original-face-rig-browser.py` للرسوم الأربعة المرجعية، مع Playwright وChromium وPillow. عند إضافة أصل جديد، طبّق فحوص المعايرة عليه أيضًا.
