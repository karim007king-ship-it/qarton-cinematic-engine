# Cinematic Visual Effects Lab

Open `index.html` from a local web server during development. Android users should use the single-file ZIP generated by the `L9-A Android preview` Actions workflow; it is designed for Chrome and Android WebView and uses Canvas 2D only.

The scene is sampled from absolute Scene Clock time, so seeking or replaying any timestamp returns the same values. The lab uses one 390×690 canvas (about 1.03 MiB at 4 bytes per pixel), no persistent offscreen buffers, and a bounded 12×12 dissolve reveal (at most 144 small Canvas 2D rectangles per frame). On mobile, keep the preview in the foreground and use a modest canvas size; device-specific frame rate and memory should still be checked on the target phone.
