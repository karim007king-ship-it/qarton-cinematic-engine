QARTON Cinematic Engine

Integrated browser showcase: layered backgrounds, two animated characters, timeline events, parallax, camera shake, particles, scene transitions and gesture-started audio cues.

Preparing integrated showcase…

Audio is generated locally (two short oscillator cues); it starts only after a user gesture. Hiding this page pauses the shared scene, character and audio timeline; returning resumes from the same cinematic time. No external assets or copyrighted music are used.

Run from the repository root with npx serve ., then open /examples/browser-smoke.html. This is a manual real-browser test, not an automated CI/browser test.
