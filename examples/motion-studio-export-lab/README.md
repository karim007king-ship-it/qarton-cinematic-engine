# مختبر تصدير Motion Studio على Android

صفحة ثابتة مستقلة عن كود المحرك والألعاب والحفظ. اختر صورة محلية؛ تبقى في الجهاز ولا تُرسل إلى خادم. يرسم Canvas داخليًا بدقة 720×1280 وبمعدل مستهدف 24 fps مع zoom/pan خفيف ومؤشر متحرك. يُخلط صوت Web Audio (نبضة 880 Hz كل ثانية تقريبًا) مع مسار Canvas في MediaRecorder.

## ما الذي يُختبر؟

- زر **افحص WebM وMP4** يعرض MIME التي يعلن عنها `MediaRecorder.isTypeSupported()` ثم ينفذ تسجيلًا قصيرًا على كل صيغة. النتيجة الإيجابية تعني أن المتصفح أنشأ Blob غير فارغ في هذه المحاولة فقط؛ يجب تشغيل الملف وحفظه وفحصه على الهاتف. النتيجة السلبية مسجلة كفشل ولا يُجرى تحويل تلقائي إلى صيغة أخرى.
- زرا 3 و10 ثوانٍ يسجلان الصيغة المختارة. تُعرض MIME الفعلية التي أعادها المسجل، والحجم والمدة المقاسة. عنصر الفيديو يتيح إعادة التشغيل، وزر الحفظ ورابط التنزيل يطلبان حفظه إلى Downloads.
- دعم `isTypeSupported()` لا يضمن التصدير أو الحفظ. دعم MP4 مسجل فقط عندما ينجح الاختبار الفعلي؛ قد يختلف Chrome عن WebView وإصدارات النظام.

## خطوات HONOR 400 Pro

1. افتح رابط GitHub Pages بعد دمج التغييرات ونشر Pages، أو شغّل `python -m http.server` من جذر المستودع وافتح `http://127.0.0.1:8000/examples/motion-studio-export-lab/` على الجهاز نفسه.
2. اختر صورة من الهاتف. اضغط **افحص WebM وMP4** واقرأ نتيجتي الاختبار؛ لا تستنتج دعم صيغة من اسم المتصفح.
3. اختر WebM واضغط **سجّل 3 ثوانٍ**. اترك الصفحة في الواجهة حتى ينتهي المقطع، ثم شغّله وتأكد من حركة الصورة وسماع النبضة.
4. اضغط **حفظ الفيديو** أو رابط التنزيل. افحص Downloads وافتح الملف بمشغل فيديو خارجي. سجّل امتداد الملف، MIME المعروض، الحجم، والمدة.
5. كرر الفحص والتسجيل مع MP4 إذا نجح اختبار MP4 الفعلي. إذا فشل، احتفظ برسالة الخطأ ولا تغيّر الامتداد يدويًا.
6. أعد تجربة WebM لمدة 10 ثوانٍ ثلاث مرات متتالية. كرر الاختبار داخل Chrome ثم في WebView الفعلي للتطبيق، مع تسجيل إصدار Chrome/Android System WebView، النتائج، وأي انهيار أو تعليق.
7. إذا كنت تفتح الصفحة في APK/WebView، زر الحفظ يعتمد دعم المضيف لتنزيلات HTML؛ نجاح عرض عنصر الفيديو وحده لا يثبت حفظه من WebView. أبلغ عن النتيجة كما هي.

## تشغيل الاختبارات الآلية

من جذر المستودع باستخدام Node 22 أو أحدث:

```sh
npm test
```

الاختبارات الآلية تتحقق من بنية الصفحة، MIME المرشحة، اختيار الصيغ المعلن عنها، المدد، امتداد MIME، وبناء JavaScript. لا تحاكي MediaRecorder حقيقيًا ولا تُعد دليلًا على نجاح Android. بيانات الجهاز ونتائج الحفظ وإعادة الفتح يجب إرفاقها بعد التجربة اليدوية.
