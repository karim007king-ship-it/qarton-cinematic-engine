# QARTON — Audio Diagnostics B2

Extract the ZIP and open index.html in Chrome. For microphone capture, use the
separate HTTPS preview; local file/content providers may deny capture even if
file analysis works. Use the comprehensive test, speak during the first five
seconds, then listen with the playback button. Copy/share/download the JSON
report; no audio bytes are included and nothing is uploaded automatically.
The saved-project check is read-only and can only inspect the same origin as
Motion Studio. A different origin reporting no project is expected.
A passing software decode or play promise does not guarantee audible hardware
output. Test on the actual Android device.
